## How HTTPS Works

**HTTPS** secures communication between a client and server using **TLS**:

1. The client connects and the server presents its **SSL/TLS certificate**.
2. The client **verifies** the certificate against trusted certificate authorities.
3. They perform a **TLS handshake** to agree on encryption algorithms and exchange keys.
4. Once the handshake completes, all data is transmitted over an **encrypted channel**, protecting it from eavesdropping and tampering.
