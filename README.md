## How HTTPS Works

HTTPS (HyperText Transfer Protocol Secure) secures communication between a client and server using TLS (Transport Layer Security). When a client connects, the server presents its SSL/TLS certificate, which the client verifies against trusted certificate authorities. They then perform a TLS handshake to agree on encryption algorithms and exchange keys. Once the handshake completes, all data is transmitted over an encrypted channel, protecting it from eavesdropping and tampering.
